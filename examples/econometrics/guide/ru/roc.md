# ROC, AUC и индекс Джини

[English](../roc.md) · [Установка](../../README.ru.md#установка)

`krroc` считает площадь под ROC-кривой и индекс Джини по графику или по прогнозам. На TI-Nspire CX II-T положите `krroc.tns` в `MyLib`, выполните `Refresh Libraries` и вводите команды на странице Calculator. В вызовах используется одна обратная косая черта `\`.

## Алгоритм построения ROC

1. Присвойте объектам истинные метки `y=1` и `y=0`. Для каждого объекта нужен скор `s`, который растёт с уверенностью модели в классе `1`.
2. Отсортируйте различные значения `s` по убыванию. Начните с порога выше всех скоров. При таком пороге прогнозов класса `1` нет и первая точка равна `(0,0)`.
3. Снижайте порог `c` и считайте прогнозом класса `1` все объекты с `s ≥ c`. Обрабатывайте объекты с одинаковым скором одновременно.
4. Для каждого порога вычислите `FPR = FP/(FP+TN)` по горизонтали и `TPR = TP/(TP+FN)` по вертикали. Здесь `FP` и `TP` — число ошибочных и верных прогнозов класса `1` соответственно. Последняя точка равна `(1,1)`.
5. Соедините соседние точки отрезками. Площадь под кривой `AUC` равна сумме трапеций. Вклад отрезка равен `(FPR₂−FPR₁)·(TPR₂+TPR₁)/2`. У вертикального отрезка ширина равна нулю. Индекс Джини равен `2·AUC−1`.

## Расчёт по графику

Передайте два списка одинаковой длины с координатами `FPR` и `TPR`. Обходите вершины от `(0,0)` до `(1,1)`, сохраняя обе точки каждой вертикали. Обе координаты лежат в `[0,1]` и не убывают. При нарушении этих условий калькулятор возвращает сообщение `ERR: ...`.

```text
krroc\auc(fpr,tpr)
krroc\gini(fpr,tpr)
```

**Вариант 3, ступень в `(0.3,0.3)`**. Путь проходит через `(0,0.3)`, `(0.3,0.3)` и `(0.3,1)`. Площадь прямоугольников равна `0.3·0.3+0.7·1 = 0.79`, индекс Джини равен `0.58`.

```text
krroc\auc({0,0,0.3,0.3,1},{0,0.3,0.3,1,1})
krroc\gini({0,0,0.3,0.3,1},{0,0.3,0.3,1,1})
```

**График со ступенью в `(2/5,2/5)`**. Путь проходит через `(0,0.4)`, `(0.4,0.4)` и `(0.4,1)`. Площадь равна `0.4·0.4+0.6·1 = 0.76`, индекс Джини равен `0.52`.

```text
krroc\auc({0,0,0.4,0.4,1},{0,0.4,0.4,1,1})
krroc\gini({0,0,0.4,0.4,1},{0,0.4,0.4,1,1})
```

## Расчёт по прогнозам

`y` и `scores` — списки одинаковой длины в порядке наблюдений. В `y` должны быть оба класса, в `scores` — конечные действительные числа. `roc` возвращает матрицу со столбцами `[FPR, TPR, порог]`. Первая строка `[0,0,max(scores)]` показывает исходную точку при строгом правиле `score > max(scores)`. Со второй строки правило включающее, `score ≥ порог`. Остальные пороги идут по убыванию, по одной строке на каждый уникальный скор. [Обозначения TI-Nspire](https://education.ti.com/html/webhelp/eg_tinspire/en/Subsystems/EG_RefGuide/Content/M_RefGuide/RG_Shortcuts_for_Entering_Math_Expressions.HTML)

```text
y:={1,0,0,1}
scores:={0.5,0.5,0.1,0.9}
krroc\roc(y,scores)
krroc\aucpred(y,scores)
krroc\ginipred(y,scores)
```

Матрица имеет строки `[0,0,0.9]`, `[0,0.5,0.9]`, `[0.5,1,0.5]`, `[1,1,0.1]`. Один общий скор `0.5` приходится на объекты разных классов. Получаем `AUC = 0.875` и `Gini = 0.75`. При подсчёте AUC по парам равные скоры положительного и отрицательного объекта дают половину балла.

## Сокращённый ввод и выбор порога

| Данные | Вызов | Результат |
|---|---|---|
| Ступенчатый график из варианта, высота 0.3 до FPR=0.3, далее высота 1 | `krroc\steparea({0,.3,1},{.3,1})` | `{.79,.58}` — AUC и Джини |
| Два списка численностей классов по группам скора, от высокого к низкому | `krroc\groupauc({1,1,0},{0,1,1})` | `{.875,.75}`. Одна группа соответствует одному значению скора |
| Метки и скоры, ложное срабатывание стоит 3, пропуск стоит 1 | `krroc\cutoff({1,0,0,1},{.5,.5,.1,.9},3,1)` | `{.9,0,0,.5,1}`: порог .9 включительно, FPR=0, TPR=.5, потери 1 |

Для `steparea` задайте m+1 строго возрастающую границу от 0 до 1 и m неубывающих высот горизонтальных участков. Вертикали имеют нулевую ширину. Для графика с наклонными отрезками используйте `auc`. В `cutoff` второй элемент ответа равен 1 для начального строгого порога выше всех положительных прогнозов (правило `score > max(scores)`), иначе действует `score >= порог`. Стоимости неотрицательны и хотя бы одна положительна. При равенстве потерь выбирается более строгий порог.
