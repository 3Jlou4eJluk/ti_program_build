## Что повторить

- **В присланных вариантах есть** ROC и индекс Джини, условные моменты, гомоскедастичность и смещение МНК, тест Уайта, критерий серий, тест Дики–Фуллера, идентификация уравнения и 2МНК. Карточки с этими темами находятся в `krguide.tns`. Вычисления выполняют `krroc`, `krdiag` и `krsys`.
- **Смежные упражнения охватывают** обычный МНК, стандартные ошибки и доверительные интервалы, ограничения и F-тест, HC0–HC3, версию Бройша–Пагана с поправкой Коенкера, Дарбин–Уотсон и Бройш–Годфри, ADF с лагами, logit/probit и метрики классификации на заданном пороге. Эти темы включены для подготовки на основе задач с фото и общего курса эконометрики. [Ф. С. Картаев, «Дружелюбная эконометрика», ЭФ МГУ](https://books.econ.msu.ru/Introduction-to-Econometrics/)

МНК помогает пересчитать обычную и вспомогательную регрессии для Уайта и Дики–Фуллера. Дарбин–Уотсон и Бройш–Годфри дополняют критерий серий вопросами о линейной связи остатков. Logit/probit и метрики порога связывают исходные прогнозы с ROC. Условия и формулы собраны в карточках раздела «Теория». [Документация statsmodels по диагностике регрессий](https://www.statsmodels.org/stable/diagnostic.html), [Документация statsmodels по ADF](https://www.statsmodels.org/stable/generated/statsmodels.tsa.stattools.adfuller.html)

Создайте страницу Calculator и сохраните вектор отклика и матрицу регрессоров. Вставьте `list►mat` из каталога. При вводе с компьютерной клавиатуры работает `list@>mat`. [Справочник TI-Nspire](https://education.ti.com/-/media/5570054579E94ABA88612EAD9D0B4165)

```text
list►mat({2,1,4,3,6,8,6},1)→y
list►mat({1,-3,1,-2,1,-1,1,0,1,1,1,2,1,3},2)→x
```

## Прогноз, ограничения и инструменты

- `krextra\predint(y,x,xnew,a)` даёт точечный прогноз, два предела для среднего и два для нового наблюдения. Передайте одну строку xnew и уровень значимости a. Классические интервалы предполагают независимые нормальные гомоскедастичные ошибки и полный ранг X.
- `krextra\wald(y,x,r,target,hc)` проверяет одно или несколько независимых линейных ограничений Rβ=target. При hc=−1 выдаёт {F,q,n−k,p}; при hc от 0 до 3 — {W,q,0,p} по асимптотическому χ². Совместная ковариация ограничений должна быть невырождена.
- `krextra\lrtest(llrest,llfull,q)` выдаёт {LR,q,p} для двух вложенных моделей максимального правдоподобия, оценённых на одних данных. Обычная аппроксимация χ² предполагает независимые регулярные ограничения и внутреннюю точку пространства параметров.
- `krextra\firstf(endog,base,omit)` даёт классический частный F, число ограничений, остаточные степени свободы, p и частный R² для исключённых инструментов на первом шаге. Для одного эндогенного регрессора передайте столбец этого регрессора, матрицу включённых экзогенных факторов и матрицу исключённых инструментов. Включите в base столбец единиц для модели с константой.
- `krextra\sargan(err,z,k)` выдаёт {J,L−k,p} для классического теста Саргана. Передайте структурные остатки 2МНК с фактическими регрессорами, полный набор из L инструментов с единицами в первом столбце и число структурных коэффициентов k. Нужны сверхидентификация и гомоскедастичность.
