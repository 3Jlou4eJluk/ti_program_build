# Диагностика регрессии на TI‑Nspire CX II‑T

[English](../diagnostics.md) · [Установка](../../README.ru.md#установка)

Библиотека `krdiag` считает численную часть задач из варианта 3 на TI‑Nspire CX II‑T без CAS. Для теста серий можно вычислить точное p-value или использовать границы из таблицы преподавателя.

## Смещение оценки

Для задания 1 смещение оценки параметра определяется как

```text
Bias(betaHat)=E(betaHat)-beta
```

Если математическое ожидание оценки равно истинному параметру, смещение равно нулю и оценка называется несмещённой. В линейной модели при `E(e|X)=0` МНК даёт `E(betaHat|X)=beta`, следовательно, также `E(betaHat)=beta`.

## Совместное распределение ошибки и регрессора

Вызов для таблицы с фотографии:

```text
krdiag\jcond({1,7},{-5,-1,1,5},[[0,1/4,1/4,0][0,1/4,1/4,0]],10^-10)
```

Столбцы результата — `x`, `P(x)`, `E(e|x)`, `Var(e|x)`. Для значений `x` с нулевой вероятностью последние два столбца заполнены нулями и не интерпретируются.

```text
[[1,1/2,0,1]
 [7,1/2,0,1]]
```

Общие моменты:

```text
krdiag\jmom({1,7},{-5,-1,1,5},[[0,1/4,1/4,0][0,1/4,1/4,0]],10^-10)
```

Результат имеет порядок `{sumP,E(x),E(e),Var(x),Var(e),Cov(x,e),E(xe),min Var(e|x),max Var(e|x)}`:

```text
{1,4,0,9,1,0,0,1,1}
```

Разложение полной дисперсии и проверка условных моментов по той же таблице

```text
krdiag\jvar({1,7},{-5,-1,1,5},[[0,1/4,1/4,0][0,1/4,1/4,0]],10^-10)
```

Результат `{1,1,0,1,1,0,1}` имеет формат
`{Var(e),E[Var(e|x)],Var(E[e|x]),minVar,maxVar,hetero,meanZero}`.
`hetero=1`, если `maxVar-minVar>tol`. `meanZero=1`, если для всех
групп выполняется `abs(E(e|x))≤tol`. Оба вывода относятся к группам с
положительной вероятностью. Каждой строке таблицы соответствует отдельное
значение `x`. Вероятности можно передать как частоты. Допуск абсолютный,
поэтому выбирайте его с учётом масштаба условных средних и дисперсий.

Вывод по варианту:

- условная дисперсия постоянна и равна `1`, поэтому условной гетероскедастичности нет;
- безусловная дисперсия также равна `1`;
- `E(e|x)=0`, поэтому выполнено условие нулевого условного среднего;
- оценки свободного члена и наклона МНК несмещённые;
- на уровне генеральных моментов смещение наклона через начало координат равно `E(xe)/E(x^2)=0`.

Последние два генеральных смещения считает:

```text
krdiag\biases({1,7},{-5,-1,1,5},[[0,1/4,1/4,0][0,1/4,1/4,0]],10^-10)
```

Результат `{bias без константы, bias наклона с константой}` равен `{0,0}`.

## Метод рядов

`krdiag\runs(e,tol)` удаляет нулевые остатки, считает знаки и серии. Результат имеет вид:

```text
{nPlus,nMinus,R,E(R),Var(R),z,nZero}
```

Для ряда из задания:

```text
e:={-5,-4.5,-1.2,-3,-5,1,5.5,5,3,4,2.1,8,-1.2,-2,-1,1,1.5,2,3,-1}
krdiag\runs(e,10^-10)
```

Получается `{11,9,5,10.9,4.63737,-2.73978,0}`. В таблице на фотографии строки и столбцы соответствуют `nPlus` и `nMinus`; таблица симметрична по ним. Для `9` и `11` при `alpha=0.05` используются границы `K1=6`, `K2=16`.

```text
krdiag\rdecision(e,6,16,10^-10)
```

Коды вывода:

- `-1` — `R≤K1`, слишком мало серий, положительная автокорреляция;
- `0` — `K1<R<K2`, оснований отвергать отсутствие автокорреляции нет;
- `1` — `R≥K2`, слишком много серий, отрицательная автокорреляция.

Для задания возвращается `-1`: рядов слишком мало, поэтому делается вывод о положительной автокорреляции. Равенства включены в критическую область согласно границам таблицы.

### Точный метод рядов

```text
krdiag\rexact(e,0.05,10^-10)
```

Результат `{nPlus,nMinus,R,pLow,pHigh,pTwo,decision,nZero}`. При
нулевой гипотезе все последовательности с наблюдаемым числом плюсов и
минусов равновероятны. Хвосты `pLow=P(R≤Rнабл)` и `pHigh=P(R≥Rнабл)`
включают наблюдаемую точку, `pTwo=min(1,2*min(pLow,pHigh))`.
При `pTwo≤alpha` функция возвращает `decision=-1` для меньшего
нижнего хвоста (признак положительной автокорреляции) и `decision=1`
для меньшего верхнего (признак отрицательной). `decision=0` означает,
что оснований отвергнуть случайный порядок знаков нет.

Для остатков из задания `pLow≈0.00488211`, `pHigh≈0.99892832`,
`pTwo≈0.00976423` и `decision=-1`. Точный расчёт поддерживает до 200 остатков после удаления
`abs(e)≤tol`. Требуется хотя бы один остаток каждого знака и
`0<alpha<1`. При нарушении этих условий возвращается `undef`.

## Тест Уайта

Алгоритм:

1. Оценить исходную регрессию и сохранить остатки `e`.
2. Построить вспомогательную регрессию `e^2` на константу, исходные регрессоры, их квадраты и попарные произведения. Полностью дублирующиеся столбцы удалить.
3. Взять `R^2` вспомогательной регрессии.
4. Рассчитать `LM=n*R^2`.
5. Сравнить `LM` с критическим значением хи-квадрат. Число степеней свободы `m` равно числу регрессоров вспомогательной регрессии без константы.

После получения `R^2` на калькуляторе:

```text
krdiag\white(n,r2,m,crit)
```

Результат `{LM,m,reject}`. `reject=1` означает, что гомоскедастичность отвергается. Например:

```text
krdiag\white(40,0.25,5,11.070)
```

возвращает `{10,5,0}`.

## Тесты Дики — Фуллера и ADF

Для DF оценивается одна из форм:

```text
Delta(y_t)=gamma*y_(t-1)+u_t
Delta(y_t)=a+gamma*y_(t-1)+u_t
Delta(y_t)=a+b*t+gamma*y_(t-1)+u_t
```

Для ADF добавляются лаги разностей `Delta(y_(t-i))`. Число лагов выбирают до получения остатков без автокорреляции. Нулевая гипотеза — единичный корень, то есть `gamma=0`. Статистика `tau=gamma/se(gamma)` сравнивается с левым критическим значением Дики — Фуллера для выбранной формы. Обычные критические значения Стьюдента здесь не подходят.

```text
krdiag\adftest(gamma,se,crit)
```

Результат `{tau,reject}`. `reject=1`, если `tau<crit`, то есть единичный корень отвергается. Если регрессия записана как `y_t=rho*y_(t-1)+u_t`, статистику считает:

```text
krdiag\dfstat(rho,se)
```

Например, `krdiag\adftest(-0.35,0.10,-2.95)` возвращает `{-3.5,1}`.

## Ограничения ввода

- Неотрицательные вероятности передаются матрицей в ориентации исходной таблицы: строки соответствуют `xv`, столбцы — `ev`.
- `tol` задаёт допуск для нулей. Для учебных данных подходит `10^-10`.
- `jcond` и `jmom` нормируют вероятности, поэтому допустимы и частоты.
- `white` проверяет только уже рассчитанную статистику LM. Вспомогательная регрессия строится штатным инструментом линейной регрессии калькулятора.
- `adftest` проверяет уже оценённый коэффициент. Лаговые переменные и регрессия создаются в Lists & Spreadsheet.
