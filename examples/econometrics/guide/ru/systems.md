# Системы одновременных уравнений и 2МНК

[English](../systems.md) · [Установка](../../README.ru.md#установка)

Библиотека `krsys` рассчитана на **TI-Nspire CX II-T без CAS**. Все проверки
ранга выполняются численно методом Гаусса. Перед контрольной положите
`krsys.tns` в `/MyLib` и выполните `Doc` → `Refresh Libraries`.

## Идентифицируемость

Для одного структурного уравнения обозначим:

- `kex` — число предопределённых переменных системы, исключённых из уравнения;
- `nrhs` — число эндогенных переменных в правой части уравнения.

Условие порядка проверяется вызовом:

```text
krsys\idord(kex,nrhs)
```

Результат `kex-nrhs`: отрицательный означает недоидентификацию, ноль — точную,
положительный — сверхидентификацию **только по условию порядка**.

Условие ранга проверяется отдельно:

```text
krsys\mrank(M,10^(-10))
krsys\idrank(M,need,10^(-10))
```

`M` — матрица коэффициентов при переменных, отсутствующих в проверяемом
уравнении, составленная по остальным структурным уравнениям. Обычно требуется
`need=G-1`, где `G` — число эндогенных переменных системы. `idrank` возвращает
`1`, если ранг достаточен, и `0` иначе.

Совместная проверка:

```text
krsys\idall(kex,nrhs,M,need,10^(-10))
```

Коды результата:

- `-1` — не выполнено условие порядка;
- `-2` — порядок выполнен, ранг недостаточен;
- `0` — точно идентифицировано;
- `1` — сверхидентифицировано.

### Проверка полной структурной матрицы

`krsys\idstruct(H,G,cm,mask,tol)` проверяет все уравнения за один вызов.
Запишите систему в виде `B*y+A*x=u` и передайте `H=[B|A]` с `G`
строками. Первые `G` столбцов соответствуют эндогенным переменным в
порядке уравнений. У каждого уравнения коэффициент при своей зависимой
переменной должен быть ненулевым. Остальные столбцы соответствуют
предопределённым переменным.

- `cm=1` указывает, что последний столбец отведён под общую константу.
  Этот столбец исключается из обеих проверок.
- При `cm=0` все столбцы после `B` участвуют в проверках. Если константа
  считается отдельной предопределённой переменной, передайте её как один
  из этих столбцов.
- При `mask=0` точные нули в `H` означают структурные исключения.
  Для численно нулевого коэффициента, который модель разрешает, передайте
  маску размеров `H` с `1` на включённых местах и `0` на исключённых.
  Коэффициент с маской `0` должен быть равен нулю.
- `tol>0` задаёт численный допуск Гаусса. Для коэффициентов порядка
  единицы подходит `10^(-10)`.

Каждая из первых `G` строк содержит
`[kex,nrhs,kex-nrhs,rank(M),G-1,code]`. Коды совпадают с `idall`.
Последняя строка содержит `[nOrderFail,nRankFail,nExact,nOver,rank(B),systemCode]`.
`nRankFail` считает уравнения с кодом `-2`. Код системы равен
`1`, если все уравнения идентифицированы и `rank(B)=G`, `0`, если
`B` обратима, но проверку провалило хотя бы одно уравнение, и `-1`
при вырожденной `B`. В последнем случае у системы нет единственной
приведённой формы. Некорректные аргументы дают `undef`.

### Система из варианта 3

```text
y1 = b12*y2 + b13*y3 + a
y2 = b23*y3 + a21*x1 + a22*x2 + a23*x3 + a24*x4
y3 = b31*y1 + a31*x1 + a34*x4
```

Здесь `y1,y2,y3` эндогенные, `x1,...,x4` экзогенные. Запишем численный
пример со столбцами `y1,y2,y3,x1,x2,x3,x4,c`.

```text
h:=[[1,-2,-1,0,0,0,0,-2][0,1,-1,-1,-2,-3,-4,0][-1,0,1,-2,0,0,-1,0]]
krsys\idstruct(h,3,1,0,10^(-10))
krsys\idstruct(h,3,0,0,10^(-10))
```

При общей константе последняя строка результата равна `[1,0,0,2,3,0]`.
При отдельном регрессоре `c` она равна `[0,0,1,2,3,1]`.
При буквенных коэффициентах ответ о ранге обосновывают условиями
ненулевых миноров, как показано ниже.

Если `a` — свободный
член и по принятой на курсе договорённости константа автоматически присутствует
во всех уравнениях, её не считают исключённым инструментом:

| Уравнение | Исключены `x` | Эндогенных справа | Условие порядка |
|---|---:|---:|---|
| `y1` | 4 | 2 | сверхидентифицировано |
| `y2` | 0 | 1 | недоидентифицировано |
| `y3` | 2 (`x2,x3`) | 1 | сверхидентифицировано |

Вторая строка проваливает необходимое условие порядка: `0-1=-1`. Поэтому при
этой стандартной трактовке недоидентифицировано второе уравнение и система в
целом. Достаточного условия ранга уже не требуется, но его провал виден и
непосредственно.

Для полной структурной проверки ранга можно составить блоки отсутствующих
переменных по двум другим уравнениям. Используйте единую запись с переносом членов в левую часть. Одновременная смена знака всей строки или всего столбца сохраняет ранг.

```text
M1=[[a21,a22,a23,a24][a31,0,0,a34]]
M2=[[1][-b31]]
M3=[[-b12,0,0][1,-a22,-a23]]
```

Проверки:

```text
krsys\idall(4,2,[[1,1,1,1][1,0,0,1]],2,10^(-10))
krsys\idall(0,1,[[1][-1]],2,10^(-10))
krsys\idall(2,1,[[1,0,0][1,1,1]],2,10^(-10))
```

При ненулевых существенных коэффициентах результаты соответственно `1`, `-1`,
`1`. Единицы здесь заменяют структурно ненулевые коэффициенты и проверяют
типичный, невырожденный случай. Формулировка задания не задаёт численные
значения коэффициентов, поэтому строгий ранговый вывод условен: при известных
коэффициентах в `M1`, `M2`, `M3` надо подставлять именно их.

Если `a` трактовать буквально как коэффициент при отдельной предопределённой
переменной `c=1`, включённой только в первое уравнение, результат меняется. Для
второго уравнения `c` становится одним исключённым инструментом: условие
порядка выполняется точно. Ранговый блок по отсутствующим `y1,c` равен
`[[1,a][-b31,0]]`; его определитель `a*b31`, с точностью до знака, ненулевой
при `a≠0` и `b31≠0`. Второе уравнение тогда точно идентифицировано. Для
третьего уравнения исключены `x2,x3,c`, оно сверхидентифицировано; например,
минор по столбцам `y2,c` матрицы
`[[-b12,0,0,a][1,-a22,-a23,0]]` ненулевой при `a≠0`. Первое уравнение остаётся
сверхидентифицированным. Значит, при буквальной трактовке отдельной константы и
указанных условиях идентифицируема вся система. На контрольной нужно явно
написать, считается ли константа общим автоматически включённым регрессором или
отдельной переменной, исключённой из уравнений 2 и 3.

## Двухшаговый метод наименьших квадратов

Подготовьте:

- `y` — вектор зависимой переменной `n×1`;
- `X` — матрицу всех регрессоров оцениваемого уравнения;
- `Z` — матрицу инструментов. Она включает все экзогенные регрессоры из `X` и
  исключённые экзогенные инструменты;
- столбец единиц добавьте и в `X`, и в `Z`, если модель содержит константу.

Инструмент должен удовлетворять двум содержательным условиям: быть экзогенным,
то есть не коррелировать со структурной ошибкой, и релевантным, то есть после
учёта остальных инструментов объяснять эндогенный регрессор. Первое условие не
проверяется одной лишь выборочной матрицей, второе видно по первому шагу и его
F-статистике.

Алгоритм 2МНК:

1. Для каждого эндогенного регрессора оценить регрессию на все столбцы `Z` и
   получить прогноз. Вместе с включёнными экзогенными регрессорами эти прогнозы
   образуют `Xhat=Pz*X`, где `Pz=Z(ZᵀZ)^(-1)Zᵀ`.
2. Оценить обычным МНК регрессию `y` на `Xhat`:
   `b=(XhatᵀXhat)^(-1)Xhatᵀy`.

Оценка 2МНК:

```text
b:=krsys\tsls(y,X,Z)
```

Функция выполняет оба шага. Эквивалентная компактная формула результата:
`b=(XᵀPzX)^(-1)XᵀPz y`.

Первый шаг можно увидеть отдельно:

```text
Xhat:=krsys\firststg(X,Z)
```

Коэффициенты, обычные гомоскедастичные стандартные ошибки и t-статистики:

```text
krsys\tslsfull(y,X,Z)
```

Столбцы результата: `[b, se, t]`. Это учебная классическая ковариационная
матрица `s²(XᵀPzX)^(-1)`. Робастные ошибки в функцию не входят.

Минимальный численный пример:

```text
y:=[[2][3][5][7][8][10]]
X:=[[1,1][1,2][1,2][1,4][1,5][1,6]]
Z:=[[1,1][1,1.5][1,2.5][1,3.5][1,5][1,6.5]]
krsys\tsls(y,X,Z)
```

Результат примера приблизительно равен `[[0.614754][1.565574]]`.

Перед вычислением проверьте, что строк у `y`, `X`, `Z` поровну, инструментов не
меньше регрессоров, а `ZᵀZ` и `XᵀPzX` невырождены. Библиотека диагностирует
ошибки размеров и очевидную нехватку инструментов. Вырождение матрицы
TI-Nspire покажет как ошибку обращения матрицы.
