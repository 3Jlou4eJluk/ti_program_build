# Эконометрика · TI-Nspire CX II-T

[English](README.md)

В установочном комплекте пять файлов калькулятора. В четырёх библиотеках 45 расчётных функций и четыре функции версии. Откройте `krguide.tns` для навигации. В 59 карточках теории сразу дан ответ, затем идут интуиция и формулы. В «Практике» каждый из 45 решателей сначала указывает, по каким данным какой результат можно получить. Дальше приведены условия применения, вызов и пример с выводом. Восемь гайдов в «Как решать» объясняют выбор метода и шаги для своих данных. «Готовые решения» содержит прежние разборы и ответы к вариантам 1–4 первой КР. Из «Теории» нажми Tab дважды для гайдов или трижды для готовых решений. На компьютере оба раздела доступны в `how-to-solve.ru.md` из архива.

В справочнике учтены слайды Д. С. Куренного «Теория эконометрики». Набери `kurennoy` или `lektsiya`, чтобы найти материалы лекции. В конце каждой связанной карточки указаны страницы. Для задачи КР1 с тремя вспомогательными регрессиями на с. 40 дан строгий порог VIF > 5. В примере на с. 59–60 совпадают порядок знаков и границы из архивной задачи о сериях.

## Установка

1. Распакуйте архив на компьютере. Включите TI-Nspire CX II-T и подключите его по USB. Для передачи файлов подойдёт [TI-Nspire CX II Connect](https://nspireconnect.ti.com/).
2. Скопируйте четыре библиотеки из каталога `MyLib` архива непосредственно в папку `MyLib` калькулятора. Справочник `krguide.tns` положите в обычную папку документов. Если четыре библиотеки из опубликованного комплекта уже установлены, для этого обновления достаточно заменить `krguide.tns`.
3. На устройстве откройте меню **Doc → Refresh Libraries**. В документе с приложением **Calculator** введите `krroc\gini({0,0,.3,.3,1},{0,.3,.3,1,1})`. Ожидаемый ответ — 0.58 или 29/50. Обратная косая черта вводится сочетанием **Shift + ÷**. [Справка TI по библиотекам](https://education.ti.com/html/eguides/nspire/EG_Nspire/EN/content/m_libraries/lb_using_library_objects.HTML)

## Поиск с клавиатуры калькулятора

Наберите русское слово латиницей. Например, `smeshchenie` или `smeschenie` для «смещения», `dispersiya` для «дисперсии», `dzhini` для «Джини». Также работают международные обозначения `roc`, `gini`, `white`, `2sls`, `adf`, `ols`. Начните ввод в любом разделе. Общая выдача показывает темы теории, гайды, готовые решения и решатели с пометкой типа. Ищите и по условию, например `serii ostatkov`, и по имени функции, например `rexact`. BM25 учитывает редкость слова, частоту и длину текста, придаёт больше веса названию и ключевым словам. Индекс включает описания и примеры задач, работает без интернета. В восьми гайдах разобрана также замена условия: например, чередующиеся знаки остатков вместо слипшихся или ломаная ROC вместо ступеней. Эти вариации составлены для подготовки по темам присланных работ.

| Клавиша | Действие |
|---|---|
| Tab | При пустом запросе сменить раздел. При введённом запросе выбрать тип результатов. Следующая введённая буква снова ищет по всем типам |
| ↑ / ↓, Enter | Выбрать и открыть карточку |
| ↑ / ↓, ← / → в карточке | Прокрутка по строкам и страницам |
| C в карточке с вызовами | Скопировать вызов в буфер TI. Повторное C выбирает следующий вызов |
| H в карточке с вызовами | Узнать, что означают имена библиотеки и функции и как выполнить вызов. H или Esc возвращает в карточку |
| Esc в карточке | Вернуться к выдаче. Ещё раз — сбросить поиск |
| Backspace | Удалить последний символ запроса |

Скопированный вызов вставьте в приложение Calculator через **Ctrl+V**. Для шаблонов подставьте свои списки, матрицы и параметры. Списки вводятся в фигурных скобках, матрицы — средствами шаблона матрицы TI. Десятичный разделитель в примерах — точка.

## Маршрут подготовки

| Когда в условии дано… | Что открыть |
|---|---|
| Совместное распределение x и ошибки | `krdiag`: сначала маргинальные вероятности, затем условные средние и дисперсии. [Разбор таблицы](guide/ru/diagnostics.md) |
| Упорядоченные остатки и таблица K1, K2 | `krdiag`: считать серии по знакам, сохранить временной порядок. [Метод рядов](guide/ru/diagnostics.md) |
| ROC-график, метки и прогнозы | `krroc`: площадь по вершинам либо ROC по скору с объединением равных значений. [Два примера ROC](guide/ru/roc.md) |
| Структурные уравнения или инструменты | `krsys`: порядок, полный ранг, две стадии МНК. [Разбор варианта и константы](guide/ru/systems.md) |
| Уайт или Дики — Фуллер | `krdiag` для уже оценённой регрессии. `krextra` для расчёта по наблюдениям. Критическое значение DF задавайте для выбранной спецификации |
| Исходная выборка для регрессии, проверки гипотез или классификации | `krextra`: МНК, стандартные ошибки и интервалы, F, диагностика остатков и бинарные модели. [Охват и примеры](guide/ru/course.md) |

Для задач с КР есть короткие пути. По ступенчатой ROC вызовите `krroc\steparea({0,.3,1},{.3,1})`, ответ — сразу {AUC, Джини}. Для упорядоченных остатков `krdiag\rexact(e,.05,0)` считает точные хвостовые вероятности и двустороннее p без таблицы. Когда требуется решение по границам из условия, используйте `krdiag\rdecision`. Для системы целиком используйте `krsys\idstruct`, для дисперсий по таблице частот — `krdiag\jvar`. Форматы ввода, смысл каждого поля и ограничения приведены в разделе «Практика».

## Проверка на TI OS

Проверочный документ `build/krcheck.tns` хранится отдельно от установочного архива. Для проверки на своей модели скопируйте его в обычные документы, откройте и нажмите **Enter**. Документ вызывает установленные библиотеки через математическое ядро TI и сравнивает результаты с контрольными значениями. Стрелки **←** и **→** переключают страницы с названиями проверок.

В Firebird на **TI-Nspire CX без CAS, OS 4.5.5.79** получено **55/55**. Дополнительно все **45/45** команд из карточек решателей выполнены с проверкой одного численного результата на команду. Проверены в том числе площадь ступенчатой ROC, связанные скоры, условные дисперсии, точный критерий серий, порядок и ранг структурной системы, 2МНК, стандартные ошибки HC3, хвосты t/F/χ², Уайт, BG, ADF и logit/probit. В том же эмуляторе проверены кириллица в английской локали TI OS, поиск латиницей по русским темам, копирование вызова, переход между разделами и прокрутка. Для **CX II-T** точный загрузочный комплект получить не удалось. Этот же документ позволяет повторить прогон непосредственно на целевой модели.

## Сборка из исходников

Для сборки нужен Python 3 и [Luna](https://github.com/ndless-nspire/Luna). Использована ревизия `a9924a9a`. Из каталога проекта выполните:

```sh
python3 build.py --luna /путь/к/Luna/luna
```

В `build/` появятся файлы калькулятора. Численные функции описаны в `libs/`, карточки — в `guide/*.json`, обработчики интерфейса — в `handbook.lua`.

Для проверки интерфейса с Python 3 и LuaJIT воспользуйтесь [командами в английской инструкции](README.md#run-the-ui-checks-with-luajit). Лицензия на растровые глифы Noto Sans Mono Regular входит в комплект. [SIL Open Font License 1.1](LICENSE-NOTO-SANS-MONO.txt)
