# Библиотека gomory v3.0 для TI-Nspire

> Историческая документация. Актуальное описание см. в [английской справке](README.md).

Библиотека для решения задач целочисленного и смешанного линейного программирования **лекционным методом Гомори** с оптимальным выбором параметра μ и отсечениями по целевой функции.

## Что нового в v3.0.0 🎓

### ⭐ Лекционная версия алгоритма Гомори!

**v3.0.0 - полная реализация метода из лекций**

#### Новое в v3.0.0:

**✅ Оптимальный выбор параметра μ**
- Функция `findmu(beta, D)`: перебор μ от 1 до D-1 с условием НОД(μ, D) = 1
- Максимизация f₀ = |μ * beta|_D для построения максимально сильного отсечения
- Гарантия: f₀ = D - δ, где δ = НОД(D, beta)

**✅ Вычисление параметра D**
- D = НОК знаменателей всех элементов текущей симплекс-таблицы
- Функция `getdenom(x)`: извлечение знаменателя из числа
- Точное вычисление D перед каждым отсечением

**✅ Отсечения по целевой функции (Z-row cuts)**
- Приоритетная проверка дробности значения Z
- Если Z дробное → строим отсечение по Z-строке
- Гарантирует строгое возрастание Z на каждой итерации

**✅ Обобщённая формула отсечения**
- Для строки i: f_j = |μ * α_ij|_D для всех небазисных переменных
- f₀ = |μ * β_i|_D
- Отсечение: Σ (f_j / D) * x_j ≥ f_0 / D

**✅ Порядок выбора строки**
1. Если Z дробное → отсечение по Z-строке
2. Иначе → первая строка с дробной целочисленной переменной

## Функции

### `gomory\gomory(mat, opt, intvars, ctypes)`

Решает задачу целочисленного и смешанного линейного программирования **лекционным методом Гомори** с двухфазным симплексом.

**Параметры:**
- `mat` - объединённая матрица ((m+1)×(n+1)), где:
  - Строки 1..m, столбцы 1..n: матрица A (коэффициенты ограничений)
  - Строки 1..m, столбец n+1: вектор b (правые части)
  - Строка m+1, столбцы 1..n: вектор c^T (коэффициенты целевой функции)
  - Элемент mat[m+1,n+1]: игнорируется (можно 0)
- `opt` - 1 для max, 0 для min
- `intvars` - вектор-строка флагов целочисленности размера 1×n (1 = целое, 0 = любое)
- `ctypes` - вектор-строка типов ограничений размера 1×m:
  - 1 = ≤ (добавляет slack-переменную)
  - -1 = ≥ (добавляет surplus + artificial переменные)
  - 0 = = (добавляет artificial переменную)

**Возвращает:**
Решение с выводом:
1. Phase 1 (если есть ограничения ≥ или =): поиск допустимого решения
2. Phase 2: оптимизация целевой функции (LP релаксация)
3. Вычисление D и оптимального μ для каждого отсечения
4. Отсечения Гомори (сначала по Z, потом по переменным)
5. Двойственный симплекс после каждого отсечения
6. Финальное целочисленное решение

**Пример из лекции:**

Задача:
```
Максимизировать: Z = 12x₁ + 7x₂
Ограничения:
  x₁ + 2x₂ ≤ 10
  x₁ + 2x₂ ≥ 2
  2x₁ + x₂ ≤ 10
  x₁, x₂ ≥ 0, целые
```

Вызов:
```
gomory\gomory([[1,2,10][1,2,2][2,1,10][12,7,0]], 1, [1,1], [1,-1,1])
```

**Ожидаемый результат (из лекции):**
- LP решение: x₁ = 10/3, x₂ = 10/3, Z = 190/3
- D = 3
- Отсечение по Z: (1/3)x₃ + (1/3)x₅ ≥ 2/3
- После двойственного симплекса: x₁ = 4, x₂ = 2, Z = 62

### Вспомогательные функции (публичные)

**`gomory\gcd(a, b)`** - Наибольший общий делитель (НОД)
- Алгоритм Евклида
- Возвращает НОД двух чисел

**`gomory\modabs(y, d)`** - Остаток |y|_D
- Вычисляет: y - D * floor(y/D)
- Используется в формуле отсечения

**`gomory\findmu(beta, d)`** - Оптимальный параметр μ
- Перебирает μ от 1 до D-1
- Условие: НОД(μ, D) = 1
- Максимизирует: f₀ = |μ * beta|_D

**`gomory\lcm2(a, b)`** - Наименьшее общее кратное (НОК) двух чисел

**`gomory\getdenom(x)`** - Извлекает знаменатель числа

**`gomory\version()`** - Возвращает версию библиотеки ("3.0.0")

**`gomory\help()`** - Выводит справку

## Алгоритм (лекционная версия)

### 1. Приведение к каноническому виду
- Добавляет slack/surplus/artificial переменные в зависимости от типа ограничения

### 2. Phase 1: Двухфазный симплекс
- Минимизация искусственных переменных
- Поиск допустимого базисного решения

### 3. Phase 2: Оптимизация
- Симплекс-метод для исходной целевой функции
- Получение оптимального LP решения

### 4. Проверка целочисленности и построение отсечения

**На каждой итерации:**

a. **Вычисление D:**
   - D = НОК знаменателей всех элементов таблицы
   - Используется `getdenom()` для каждого элемента

b. **Выбор строки для отсечения:**
   1. Проверить Z-строку: если Z дробное → использовать Z-строку
   2. Иначе: найти первую строку i, где x_i целочисленная и дробная

c. **Вычисление оптимального μ:**
   - β = значение в правой части выбранной строки
   - μ = `findmu(floor(β*D + 0.5), D)`
   - Гарантия: НОД(μ, D) = 1 и f₀ максимально

d. **Построение отсечения:**
   - Для каждой небазисной переменной j:
     - α_ij = коэффициент в таблице
     - f_j = |μ * floor(α_ij * D + 0.5)|_D
   - f_0 = |μ * floor(β * D + 0.5)|_D
   - Добавить строку: Σ f_j * x_j + slack = -f_0

e. **Двойственный симплекс:**
   - Восстановление допустимости после добавления отсечения
   - Пивотирование до получения всех неотрицательных b

### 5. Финальное решение

**Стоп когда:**
- Все целочисленные переменные приняли целые значения
- ИЛИ достигнут лимит итераций (20 отсечений)

## Примечания

1. **Формат входных данных:**
   - Матрицы и векторы вводятся в формате TI-Nspire: `[[1,2][3,4]]`
   - Строка opt: 1 для max, 0 для min

2. **Ограничения:**
   - Поддерживаются все типы ограничений: ≤, ≥, =
   - Все переменные должны быть неотрицательными
   - Максимум 20 отсечений Гомори
   - Максимум 30 итераций на каждую фазу симплекса

3. **Производительность:**
   - Для задач 2-3 переменных: ~10-30 секунд
   - Для больших задач может требоваться больше времени

4. **Отличия от v2.3.0:**
   - v2.3.0: упрощённая формула отсечения (без μ, без D)
   - v3.0.0: полная лекционная версия с оптимальным μ и D

## Теория

**Метод отсечений Гомори (лекционная версия)** решает задачи целочисленного линейного программирования путем:

1. Решения LP релаксации симплекс-методом
2. Если решение нецелое:
   - Вычисление D (НОК знаменателей)
   - Проверка дробности Z
   - Выбор строки для отсечения (Z или переменная)
   - Нахождение оптимального μ
   - Построение отсечения по обобщённой формуле
3. Решения новой задачи двойственным симплексом
4. Повтора до получения целочисленного решения

**Обобщённая формула отсечения:**

Для строки i с базисной переменной x_i = β/D (где β дробное):

```
Исходное равенство: x_i + Σ λ_ij * x_j = β/D

где λ_ij = α_ij / D (коэффициенты в таблице)

Выбираем оптимальное μ: НОД(μ, D) = 1, f₀ = |μ*β|_D → max

Для каждого j: f_j = |μ * α_ij|_D

Отсечение: Σ (f_j / D) * x_j ≥ f_0 / D
```

**Приоритет отсечений:**
1. Если Z дробное → отсечение по Z-строке (гарантирует рост Z)
2. Иначе → отсечение по первой дробной целочисленной переменной

## Примеры задач

### Задача 1: Из лекции
```
max Z = 12x₁ + 7x₂
x₁ + 2x₂ ≤ 10
x₁ + 2x₂ ≥ 2
2x₁ + x₂ ≤ 10
x₁, x₂ ≥ 0, целые

gomory\gomory([[1,2,10][1,2,2][2,1,10][12,7,0]], 1, [1,1], [1,-1,1])

Ожидаемый результат:
LP: x₁=10/3, x₂=10/3, Z=190/3
D=3, μ (оптимальное)
Отсечение по Z
Итог: x₁=4, x₂=2, Z=62
```

### Задача 2: Простая (только ≤)
```
max Z = x₁ + x₂ + 5x₃
2x₁ + 3x₂ + 3x₃ ≤ 8
x₁ + 4x₂ + 2x₃ ≤ 7
x₁, x₂, x₃ ≥ 0, целые

gomory\gomory([[2,3,3,8][1,4,2,7][1,1,5,0]], 1, [1,1,1], [1,1])

Ответ: x=(1,0,2), Z=11
```

### Задача 3: Смешанные переменные
```
max Z = 3x₁ + 2x₂
x₁ + x₂ ≤ 4
2x₁ + x₂ ≤ 6
x₁ целое, x₂ любое

gomory\gomory([[1,1,4][2,1,6][3,2,0]], 1, [1,0], [1,1])
```

## Устранение неполадок

**Проблема:** "Library document not found"
- Решение: Убедитесь, что файл в `/MyLib` и выполнен Refresh Libraries

**Проблема:** "Max cuts reached"
- Решение: Задача требует более 20 отсечений или не имеет целочисленного решения

**Проблема:** "Phase 1: max iter" или "Phase 2: max iter"
- Решение: Задача слишком сложная или некорректная, проверьте входные данные

**Проблема:** Программа зависла
- Решение: Нажмите [ON] для прерывания, проверьте корректность данных
