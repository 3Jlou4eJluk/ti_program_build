# Gomory changelog

## 3.0.5

The checked-in TI-BASIC source reports version `3.0.5`. It prints the linear relaxation, selects a cut from a fractional basic decision-variable row and reoptimizes with dual simplex. The [quick reference](QUICK_REFERENCE.md) describes this version.

## 3.0.0 · 2025-12-22

The historical release notes describe a lecture variant that selected cuts using a common positive denominator and a coprime multiplier. The notes also describe cuts from the objective row. The source retains the numerical helper functions from that variant.

## 2.3.0 · 2025-10-19

The historical release notes describe expanded pivot output for the optimization phase and dual simplex, including the ratio tests used to select pivots.

## 2.2.0 · 2025-10-19

The historical release notes describe detailed problem data and constraint verification in the final output.

## 2.1.0 · 2025-10-19

The historical release notes describe structured output for integrality checks, cuts and the final solution, along with the canonical form and relaxation.

## 2.0.0 · 2025-10-18

The historical release notes record the first stable teaching version with two simplex phases, Gomory cuts and dual simplex after each cut.
