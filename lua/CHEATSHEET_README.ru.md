# Economics Theory Cheat Sheet

> Историческая документация. Актуальное описание см. в [английской справке](CHEATSHEET_README.md).

Интерактивная шпаргалка по экономической теории для TI-Nspire.

## Описание

Lua-программа для просмотра теоретических вопросов по экономике с навигацией и прокруткой.

## Функционал

### Главное меню
- Ввод номера вопроса
- Список вопросов с предпросмотром
- Навигация стрелками вверх/вниз
- Отображение текущего вопроса

### Поиск по заголовкам (код 1488)
- Поиск подстроки в названиях вопросов
- Регистронезависимый поиск
- Результаты в реальном времени
- Отображение номера и заголовка вопроса

### Полнотекстовый поиск (код 228) ⭐ NEW
- Поиск по всему содержимому вопросов
- Поиск в заголовках И в тексте контента
- Регистронезависимый поиск
- Показывает контекст найденного совпадения
- Один результат на вопрос (первое совпадение)
- Двухстрочное отображение: заголовок + контекст

### Поиск на странице (клавиша F) ⭐ NEW
- Поиск внутри открытого вопроса
- Активация клавишей **F** при просмотре вопроса
- Желтое поле ввода в верхней части экрана
- **Желтое выделение** найденных строк
- Жирный шрифт для найденных строк
- Автоматическая прокрутка к первому совпадению
- Счетчик совпадений (N matches)
- ESC закрывает поиск, возвращает к просмотру

### Просмотр вопроса
- Отображение контента с формулами (LaTeX-нотация)
- Вертикальная прокрутка (↑↓) - 15 строк на экран
- Навигация между вопросами (←→)
- Возврат в меню (ESC)
- Индикатор позиции: `Q 1/X | Line Y/Z`

## Управление

### В меню
- **Цифры** - ввод номера вопроса
- **↑↓** - навигация по списку вопросов
- **Enter** - открыть выбранный вопрос
- **Tab** - список всех вопросов
- **1488** - поиск по заголовкам (Easter egg)
- **228** - полнотекстовый поиск (Easter egg) ⭐ NEW
- **ESC** - выход из программы

### В режиме поиска (1488 или 228)
- **Буквы/цифры** - ввод поискового запроса
- **↑↓** - навигация по результатам
- **Enter** - открыть выбранный вопрос
- **Backspace** - удалить последний символ
- **ESC** - возврат в меню

### При просмотре вопроса
- **↑↓** - прокрутка текста вверх/вниз (построчно)
- **+ / -** - постраничная прокрутка вниз/вверх (~15 строк)
- **Tab** - постраничная прокрутка вниз (Page Down)
- **←→** - переход к предыдущему/следующему вопросу
- **F** - поиск на текущей странице ⭐ NEW
- **ESC** - возврат в меню

### При поиске на странице (F)
- **Буквы/цифры** - ввод поискового запроса
- **Backspace** - удалить последний символ
- **↑↓** - прокрутка (навигация по странице)
- **ESC** - закрыть поиск на странице

## Текущий контент

### Вопрос 1: Modelirovanie ekonomiki i makroagenty

**Разделы:**
1. **GLAVNYJ TEZIS** - главный тезис о моделировании экономики
2. **OSOBENNOSTI MODELIROVANIYA** - особенности моделирования
   - Почему нужны модели (3 причины)
   - Два уровня системы (производственно-технологический, социально-экономический)
   - Этапы построения модели (5 этапов)
3. **MAKROEKONOMICHESKIE AGENTY** - макроэкономические агенты
   - Концепция агента
   - Описание поведения (теоретико-игровой подход)
   - Ограничения агента (внутренние и внешние)
4. **CHETYRE BAZOVYH AGENTA** - 4 базовых агента
   - Домохозяйства (функция полезности, решения)
   - Фирмы (производственная функция, оптимизация)
   - Государство (бюджетное ограничение, инструменты)
   - Центральный банк (денежная эмиссия, регулирование)
   - Внешний мир (для открытой экономики)
5. **VZAIMODEJSTVIE: RYNKI** - взаимодействие через рынки
   - 4 типа рынков
   - Концепция равновесия (Вальрас, Эрроу-Дебрё)
6. **BALANSY** - балансовые соотношения
   - Материальный баланс агента
   - Основное макроэкономическое тождество: Y = C + I + G + NX

**Объем:** ~180 строк контента с формулами и пояснениями

## Формат контента

Все формулы представлены в LaTeX-подобной нотации в виде текста (транслит):

```
U = SUM_{t=0}^{inf} beta^t u(C_t, L_t)
Y = F(K, L)
max_{K,L} {pY - wL - rK}
pri Y = A K^alpha L^{1-alpha}
Y = C + I + G + NX
```

Математические обозначения:
- `^` - степень (beta^t, K^alpha)
- `_` - индекс (C_t, L_t, X_i^a)
- `SUM` - сумма
- `Delta` - изменение
- `inf` - бесконечность

## Добавление новых вопросов

Откройте `lua/econ_cheatsheet.lua` и найдите секцию `-- PLACE FOR NEW QUESTIONS`.

Добавьте новый вопрос в формате:

```lua
{
    num = 2,
    title = "Vash zagolovok voprosa (translit)",
    content = {
        {text = "RAZDEL 1:", bold = true},
        {text = "Tekst stroki 1"},
        {text = "Tekst stroki 2"},
        {text = " "},  -- pustaya stroka
        {text = "Formula: Y = C + I + G"},
        {text = " "},
        {text = "RAZDEL 2:", bold = true},
        {text = "Eshe tekst..."}
    }
}
```

**Важно:**
- `num` - номер вопроса (увеличивается по порядку)
- `title` - заголовок ТРАНСЛИТОМ (без кириллицы)
- `content` - массив строк
- `{text = "...", bold = true}` - жирный текст (для заголовков)
- `{text = " "}` - пустая строка (для разделения разделов)

После добавления:
```bash
./scripts/build-lua.sh econ_cheatsheet
```

## Примеры использования

### Пример 1: Открыть вопрос напрямую
1. В меню введите `1`
2. Нажмите **Enter**
3. Откроется вопрос #1 "Modelirovanie ekonomiki i makroagenty"

### Пример 2: Прокрутка длинного вопроса
1. Откройте вопрос #1
2. Используйте **↑↓** для прокрутки
3. Внизу экрана: `Q 1/1 | Line 15/180` - показывает позицию

### Пример 3: Быстрая навигация
1. Откройте любой вопрос
2. Нажмите **→** для перехода к следующему (пока только #1)
3. Нажмите **←** для возврата

### Пример 4: Поиск по заголовкам (1488)
1. В главном меню введите `1488`
2. Откроется экран поиска с синим полем ввода
3. Введите `model` (без кавычек)
4. Сразу появятся результаты с совпадениями в заголовках
5. Используйте **↑↓** для выбора нужного вопроса
6. Нажмите **Enter** для открытия

### Пример 5: Полнотекстовый поиск (228) ⭐
1. В главном меню введите `228`
2. Откроется экран полнотекстового поиска с зеленым полем ввода
3. Введите ключевое слово, например `poleznost` или `beta`
4. Результаты показывают:
   - Строка 1: номер вопроса и заголовок
   - Строка 2: контекст найденного совпадения (первые 40 символов)
5. Используйте **↑↓** для навигации по результатам
6. Нажмите **Enter** для открытия вопроса
7. **ESC** - возврат в меню

### Пример 6: Поиск формул
1. Введите `228` для полнотекстового поиска
2. Введите `SUM` или `beta^t` или `K^alpha`
3. Найдутся все вопросы с этими формулами
4. Откройте нужный вопрос для просмотра полного контекста

### Пример 7: Поиск на странице (F) ⭐
1. Откройте любой вопрос (например, введите `1` в меню)
2. Нажмите клавишу **F**
3. Появится желтое поле "Find:" вверху экрана
4. Введите поисковый запрос, например `agent` или `poleznost`
5. Все строки с совпадениями **выделятся желтым** фоном
6. Текст станет жирным
7. Справа от поля ввода появится счетчик: "| 5 matches"
8. Страница автоматически прокрутится к первому совпадению
9. Нажмите **ESC** чтобы закрыть поиск и вернуться к обычному просмотру

### Пример 8: Быстрый поиск термина в открытом вопросе
1. Вы читаете вопрос и встретили незнакомый термин
2. Нажмите **F** → введите часть термина
3. Все упоминания термина выделятся желтым
4. Используйте **↑↓** для навигации по странице
5. **ESC** - вернуться к чтению без выделения

## Сравнение типов поиска

| Характеристика | Поиск по заголовкам (1488) | Полнотекстовый (228) | Поиск на странице (F) |
|----------------|----------------------------|----------------------|----------------------|
| Активация | Код `1488` в меню | Код `228` в меню | Клавиша `F` в вопросе |
| Область поиска | Только названия вопросов | Все вопросы: заголовки + контент | Текущий открытый вопрос |
| Цвет поля | Синий | Зеленый | Желтый |
| Выделение | Нет | Нет | Желтый фон + жирный шрифт |
| Отображение | Одна строка: №  + заголовок | Две строки: заголовок + контекст | Выделение в тексте вопроса |
| Результаты | Список вопросов | Список вопросов | Прямо в тексте |
| Автоскролл | Нет | Нет | Да, к первому совпадению |
| Счетчик | Да | Да | Да (N matches) |
| Когда использовать | Знаете тему вопроса | Не знаете где искать | Уже открыли нужный вопрос |
| Пример | `model`, `agent` | `poleznost`, `SUM`, `beta` | `Valpas`, `funkciya` |

**Рекомендации:**
- **1488** - быстрый поиск вопроса по названию темы
- **228** - поиск вопросов по терминам и формулам (когда не знаете, в каком вопросе искать)
- **F** - поиск внутри открытого вопроса (подсветка всех упоминаний)

## Технические детали

- **Размер экрана:** 318x212 пикселей (TI-Nspire CX)
- **Видимых строк:** ~15-17 строк на экране
- **Высота строки:** 10 пикселей
- **Шрифт:** sansserif, размер 7 (контент), 11 (заголовок)
- **Прокрутка:** автоматический расчет по количеству строк

## Структура файла

```
lua/econ_cheatsheet.lua
├── Global state (экран, вопрос, прокрутка, ввод, поиск)
├── Questions database (массив вопросов)
├── Search functions
│   ├── searchQuestions() - поиск по заголовкам
│   └── searchQuestionsFullText() - полнотекстовый поиск
├── UI helpers (функции отрисовки)
├── Screens
│   ├── Menu screen (главное меню)
│   ├── List view (список всех вопросов)
│   ├── Search screen (поиск по заголовкам, код 1488)
│   ├── Fulltext search screen (полнотекстовый поиск, код 228)
│   └── Question view (просмотр вопроса)
├── Main rendering (on.paint)
└── Event handlers
    ├── on.arrowKey() - навигация
    ├── on.enterKey() - выбор/открытие
    ├── on.charIn() - ввод символов + коды активации
    ├── on.backspaceKey() - удаление символов
    ├── on.escapeKey() - возврат в меню
    └── on.tabKey() - список вопросов / Page Down
```
